# Package-tier external effects can refuse without a named reason

maximalUnverifiable answers unverifiable whenever the effect scan is
non-empty, but the selected reason comes only from scan.preferred - and
the body scan's unaudited-standard-operation arm adds effects without
ever feeding the preferred selection. A subject refused solely by such
an effect serves the bare "external dependence" fallback: the verdict
names no package, no symbol, no channel. Surfaced while placing the
audited-sync admission - the hunt for the unnamed site cost a
diagnosis pass that a named reason would have skipped.

Fix direction: every scan.add site contributes to the preferred
selection under the existing cause-preference order, so a non-empty
effect set always carries its highest-ranked name.

Lands: when the external-effect scan's reason selection is next
changed, or with the first field diagnosis blocked on an unnamed
verdict.
