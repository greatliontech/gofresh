# Package-scan observability refusals block oracle evidence serving

Lands: cross-tool train chunk 86 (the startup-effect-precision
activation decision's vehicle; this chain is the activating
evidence).

## The demonstrated chain (2026-08-15, gomutant fixture probes)

A consumer test subject (an oracle) without a `//gofresh:pure`
assertion can never serve from recorded evidence in a real repository:

1. The observed-discharge gate requires a POSITIVE observability
   proof: `view.go`'s positives gate is
   `compatibleObservationProof(...) && rec.ObservationProof.Observable`.
   The recorded `"caller assertion"` (view.go's observed-capture
   constant) asserts observation completeness only - it is
   compatibility-hashed, never an observability substitute.
2. Real proofs refuse wholesale: the package-scan tier prefixes
   `"package scan: "` onto `"reaches unaudited standard operation
   unsafe.Pointer"` (closure/observability.go's scan over the scope;
   unsafe detection in the analyzer), and a real dependency graph
   (reflect-heavy libraries) reaches unsafe practically everywhere.
3. With the proof refused, completed observation evidence cannot
   substitute for I/O dependence
   (`decideAfterClosureObserved`'s observed leg never fires), so every
   env- or file-reading oracle re-measures forever; only
   purity-asserted subjects serve.

Field confirmation: the ocifs consumer's campaigns reported `0
cached` on every run and its committed findings document was empty at
every version it ever carried - its oracles read files and env and
carry no purity assertions. The gomutant-side loop trust work
(version surface, loud non-persistence, staged-loop verification,
lock hygiene) landed separately; reuse for real oracles waits on this
precision work.

## Fix direction

Narrow the package-scan refusal so an oracle's observability judgment
prices what the subject reaches rather than what the scan scope
contains - the startup-effect-precision plan's precision ladder is
the natural home; alternatives (an observability assertion surface
mirroring the purity directive, or an audited-unsafe set) trade
soundness for reach and need the design pass the activation decision
owns.
