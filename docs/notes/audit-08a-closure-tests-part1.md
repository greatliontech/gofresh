## 5. Coherent Static-Analysis Testing Framework Architecture

To make `closure` testing fast, orthogonal, and easy to reason about, reorganize the suite into **three explicit execution tiers** with strict rules on setup cost:

```
┌────────────────────────────────────────────────────────────────────────────┐
│ Tier 0: Pure In-Memory & Mini-SSA Unit/Property Tests (< 50ms total)       │
│  - Runs unconditionally (NEVER skips in -short)                            │
│  - Zero `go` subprocesses (`go env`, `go list`, `packages.Load` forbidden) │
│  - Uses:                                                                   │
│    1. Direct predicate/rank/digest calls (`auditset`, `canonicalDigest`)   │
│    2. `maximalFileEffectsContent` / `testingMethodEffectsContent`          │
│    3. Synthetic `&Hasher{lists: ..., fileMemo: ...}` for compartments,     │
│       contributions, cgo `#include` scanner, and memo stores               │
│    4. In-memory `parser.ParseFile` + `types.Config.Check` +                │
│       `ssa.NewProgram` (`buildMiniSSA(t, filesMap)`) for `arta`,           │
│       `tier2Analyzer`, `closedInvokeTargets`, `walkCellReferrers`,         │
│       and cancellation checks                                              │
├────────────────────────────────────────────────────────────────────────────┤
│ Tier 1: Single-Pass Toolchain & Stdlib Typecheck Canaries (~200ms)         │
│  - Loads `"testing"` syntax/types ONCE via package-scoped `sync.OnceValues`│
│    for all declaration-inventory checks (`logging`, `subtest`, `pacing`)   │
│  - Tests `TakeEnvSnapshot` / `NewBracketAt` / `implicitImportName`         │
├────────────────────────────────────────────────────────────────────────────┤
│ Tier 2: Shared-Universe End-to-End Integration Suite (`!testing.Short()`)  │
│  - ONE package-scoped (or suite-scoped) `fixturePrograms` owner over the   │
│    entire `closure/fixtures/...` corpus so each fixture package is         │
│    listed, typechecked, and SSA-built AT MOST ONCE per `go test` invocation│
│  - ONE consolidated temp-module builder for dynamic multi-package scenarios│
│    (batch mask boundary, recompiled triangle, stdlib positive admissions)  │
└────────────────────────────────────────────────────────────────────────────┘
```
